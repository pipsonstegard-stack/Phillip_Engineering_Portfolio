Solar-Battery
Modeling Application

A Python application developed to model residential solar production, battery operation, utility costs, and long-term system performance. The project brought together energy-system modeling, data processing, a desktop interface, and automated reporting.

PythonpvlibNumPyPandasMatplotlibSQLiteTkinter

Project overview

The goal of this project was to create a flexible modeling tool for evaluating residential solar and battery systems. The application combines solar production estimates, household electricity demand, battery behavior, and utility-rate structures to help compare system configurations and understand their financial and operational implications.

Engineering and software implementation

The application was organized into separate modules for configuration, model data, energy calculations, data handling, and the graphical interface. Python was used to connect the modeling workflow and present results through a desktop GUI.

  • Solar production: Used location-specific weather and solar-resource data to estimate photovoltaic energy production.
  • Battery operation: Modeled battery state of charge, operating limits, charging, and discharging behavior.
  • Utility costs: Incorporated utility-rate structures, including time-of-use periods, fixed charges, and energy rates.
  • Data and reporting: Used structured data handling and generated visual and report-based outputs for comparing scenarios.

My contributions

I developed the application’s modeling and software workflow, including the Python modules, data structures, GUI, and reporting functionality. I also prepared user documentation to explain installation, configuration, model assumptions, and the use of the application.
